# ⚽ FIFA World Cup 2026 Predictor

A web application that predicts FIFA World Cup match outcomes using team statistics such as FIFA rankings, attack strength, defensive strength, and recent form.

🌐 **Live Demo:**https://world-cup-predictor-vxtcpnmjhynopm8uzztaoq.streamlit.app/

---

## 📌 Features

- 🔮 Predict match outcomes between two teams
- 📊 Win probability visualization
- 📈 Team comparison using radar charts
- 🏆 Knockout tournament bracket
- 📋 Team statistics dashboard
- 📱 Responsive interface for desktop and mobile

---

## 🛠 Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib

---

## ⚙️ Prediction Model

The prediction is based on a weighted statistical model using:

- FIFA Ranking
- Attack Rating
- Defense Rating
- Recent Team Form
- Home/Away Advantage

The application calculates the probability of each team winning and estimates the possibility of a draw.

---

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/positivefunctionIN/World-Cup-Predictor.git
```

Navigate to the project

```bash
cd World-Cup-Predictor
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run fifa-world-cup-predictor.py
```
